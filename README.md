# AlpharettaList.com

The local guide to Alpharetta, Georgia: restaurants, things to do, events, news and a local business directory. Built on the same engine as WellingtonList.com.

## How it works
- **Static site** generated by `scripts/build.mjs` (Node, no dependencies) into `/docs`, served by GitHub Pages at alpharettalist.com.
- **Content** lives in `src/`:
  - `src/data/places.json` directory listings (restaurants, attractions, parks, shopping, services)
  - `src/data/events.json` events calendar
  - `src/data/posts.json` + `src/content/blog/<slug>.html` blog posts (metadata, FAQs, sources + article body)
  - `src/assets/` styles, scripts, `config.js` (form endpoint and GA4 ID — both currently empty; forms fall back to email)
- **Submissions**: forms fall back to a pre-filled email to hello@alpharettalist.com until a Google Apps Script endpoint is set in `config.js` (same pattern as WellingtonList).
- **GitHub Action** (`.github/workflows/build.yml`) rebuilds on every push and daily.
- **No ads or sponsor slots** on this site by design.

## Add a blog post
1. Add metadata (title, description, FAQ, sources) to `src/data/posts.json`
2. Add the article body to `src/content/blog/<slug>.html`
3. Optional: add a 1600x900 cover at `src/covers/<slug>.jpg`
4. Push. The sitemap, RSS feed, blog index and homepage update automatically.

## Design
Palette: "Avalon Luxe" — espresso charcoal (#211E1B / #2B2520) with champagne gold (#C9A24B) accents, serif "A" crest shield logo.

## SEO built in
Pre-rendered HTML, unique titles and descriptions, canonical URLs, Open Graph and Twitter cards, JSON-LD (Organization, WebSite, BreadcrumbList, NewsArticle, FAQPage, ItemList, Event and LocalBusiness types), XML sitemap, robots.txt and RSS feed.
